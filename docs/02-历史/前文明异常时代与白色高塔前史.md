# 前文明异常时代与白色高塔前史

> 最后更新：2026-08-23

## 一、前文明异常时代

约20世纪40年代末至50年代，太阳系开始进入“群星”的影响范围。

群星是能够被天文学手段直接观测的实体天体，但其携带或维持的解释秩序与太阳系常态不同。目前没有证据表明群星具有智慧、以地球或人类为目标，或主动创造神秘意义。

随着群星接近：

- 现实轴在地球上的解释垄断逐渐减弱；
- 原本极少、极弱的天然异常开始更频繁地表现；
- 神秘使数量增加；
- 部分基础实验出现无法解释的不稳定；
- 高度依赖微观可重复性的技术体系逐渐失去部分可靠性。

异常并非由群星创造。在群星到来以前，人类意义、可能的非人类观察遗留以及少数解释权通道已经存在，只是绝大多数神秘叙述无法在强常态下长期取得现实解释权。

宏观机械、电气、化工、材料与冶金技术并未立即失效，但超大规模集成电路等高度依赖微观一致性的工业受到较大影响。真空管、继电器、模拟电路、电机械系统、湿件计算与神秘学计算等路线由此重新获得重要性。

## 二、白色高塔的前身

二战结束后，各国先后建立了各自的秘密异常处理机关。它们的法统、隶属关系和工作方式并不一致：有的来自公务员与科研系统，有的与军政体系结合，也有的主要依托地方既有的神秘学传统。

这些机关的早期职责通常包括：

- 发现、隐瞒与封锁异常；
- 组织跨国异常处置；
- 建立共享数据库和全球对照测量网络；
- 研究神秘使与天然异常；
- 判断基础实验失稳究竟来自仪器、环境、新规律还是现实条件本身。

面对持续扩大的共同威胁，以及保存人类希望的需要，绝大多数已经形成成熟神秘学体系的国家签署《白塔协议》。签约方自愿将各自原有机关的相关部分改组为地方白塔机关，统一使用“白塔”这一名称，并接受共同协作所需的最低制度接口；这些机关并未因此被改造成由纯白之湖垂直指挥的分部。

协议后的协作体系最早的核心优势不是统治权，而是各地单独无法获得的全球对照数据。

随着异常数量增加，各地白塔与共同机构逐渐共同建立和完善：

- 指称与真名理论；
- 神秘使筛选、培养与协作体系；
- 奇物工程；
- 禁绝技术；
- 天然异常利用；
- 风险分类与实验复现标准；
- 初步神秘学工业。

前文明晚期的异常规模已经无法继续隐藏时，白塔体系逐步公开，并成为跨国神秘学标准和异常管理体系的核心。

各地白塔始终是不同地方法统下的公共机关，保有高度自治和显著制度差异。它们共同设立驻纯白之湖的白塔中枢，以处理自身无法单独承担的共同事务；中枢并不由此取得地方民政或各地白塔内部制度的当然管辖权。

## 三、纯白之湖空泡、摩柯与白色高塔

前文明科研体系在前伦敦区域发现了被称为“纯白之湖”的稳定空泡，并在其内部建立核心研究与工业设施。

空泡内部能够较稳定地复现外界已经开始失稳的基础实验，许多神秘现象进入后会减弱、失去传播能力或难以外显。

纯白之湖不是单一异常主体，而是作用方向偏向现实稳定的异常复合区域。现有工程模型认为，它由长期地理结构、大规模原生禁绝金属富集、区域历史叙述及未知解释权结构共同形成；究竟由哪一项主导、是否与太阳常态存在特殊关系，仍无定论。

白塔中枢及其共同设施在此集中建设：

- 禁绝材料研究中心；
- 异常实验设施；
- 神秘使训练体系；
- 神秘学工业母床；
- 文明档案与战略设施。

一座以原生禁绝金属为核心材料的大型塔状设施最终建成，并被称为“白色高塔”。这座建筑逐渐成为协议共同机构的象征；“白塔”也由此成为中枢、各地改组机关及其共同制度身份共享的名称。

点燃历史后，前伦敦节点逐渐发展为[摩柯](../03-地理/摩柯.md)。现代语境中的“白色高塔”因而可以同时指一座建筑、驻纯白之湖的共同中枢、各地同名公共机关，以及由它们共同构成的文明协作体系。

纯白之湖拥有目前已知最重要的原生禁绝金属矿床之一，其样品富集程度高、异常杂质少、人类可检出的附带神秘叙述相对有限，具有极高工程适用性。

这些矿床不是与空泡无关的普通资源。原生禁绝金属已经长期参与区域稳定结构；过度开采可能降低稳定性、增强外部异常渗透或改变空泡性质。因此白塔对其实施严格限制。

这并不等于“空泡由一种金属单独产生”。禁绝金属、地理结构、历史关系和未知因素各自贡献多大，仍需独立观测。

## 四、禁绝材料与神秘学工业

禁绝金属不是单一元素，也不是宇宙天然划定的纯粹物质类别，而是白色高塔依据工程表现建立的材料分类。

它们通常令【禁绝】【保持自身】【维持同一】【拒绝外来规定】等人类近似叙述持续取得解释权，可以异常地抵抗神秘作用、削弱传播并维持局部边界。

前文明强常态时期，这些材料的超常禁绝性质难以外显，在常规观察中只是普通金属、矿物、天然合金或特殊地质材料。常态减弱后，部分样品关于【稳定／禁绝】的神秘叙述开始持续取得现实解释权。

现代禁绝材料主要分为：

1. 自然形成、原始观察来源可能未知的原生禁绝金属；
2. 由普通材料经长期定向诱导形成的嬗变禁绝金属；
3. 面向批量工程使用的禁绝合金与人工稳定材料。

人类可以复制化学成分、晶格和部分工程功能，却不能仅凭相同成分复制某个原生异常的个体历史。与此同时，人类已经能够通过嬗变与合金工程制造可控、可加工、能够量产的禁绝材料。

因此，真正支撑现代文明的并非少数“最强样品”，而是原生样品、母床、嬗变工艺和大规模工业材料共同构成的体系。

## 五、白塔的前文明地位

白色高塔在0年前并非统辖各国内政的统一世界政府。各地白塔的共同中枢仅处理跨地区、跨大洲和文明级事项；其影响力主要来自：

- 全球异常信息与对照数据；
- 风险、测试、术式与奇物标准；
- 纯白之湖内的高端神秘学设施；
- 原生禁绝样品与神秘学工业母床；
- 低风险、可重复的神秘使培养体系；
- 专业异常处置与反神秘行动力量；
- 维持跨国关键系统所形成的功能合法性。

白塔的基本政策并非消灭全部神秘现象，而是控制风险、理解机制、建立标准，并将可控部分转化为人类能够长期使用的技术。
