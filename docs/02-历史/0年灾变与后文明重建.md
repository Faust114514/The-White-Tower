# 0年灾变与后文明重建

> 最后更新：2026-08-23

## 十五、文明火种体系

前文明对关键火种人员实施了特殊历史处理，尽量同时保护现实状态【此人现在存在】与神秘叙述中的人格连续性，并减少其当前存在对复杂旧历史解释的依赖。

这类人员可能在0年后保持身体、人格、知识与主要记忆，却失去大量旧历史叙述的可追溯性，并从0年开始重新积累彼此一致的现实经历与神秘解释。

火种保存并不只依赖白塔。整个体系包括：

1. **白塔核心火种：** 保存最难重新获得的高阶神秘使、工程师、科学家、医学与农业专家、母床、数据库、样本和关键设备；
2. **区域节点：** 维持具有水、食物、医疗、教育、能源、工业、神秘使与基本行政能力的完整社会；
3. **次级庇护区：** 地下设施、军事基地、地方避难所、稳定设施与物资中心；
4. **非计划幸存者：** 依靠地理、自给能力、船队、地方神秘使或偶然保护存续的个人和社区。

节点建设会使用禁绝材料，其中部分高等级设施需要原生样品作为稳定核心。纯白之湖矿床的工业价值因此与空泡保存发生直接张力。

白塔优先以嬗变材料和可量产合金满足常规需求；涉及纯白之湖原生样品的开采，必须同时评估节点收益与空泡长期损耗。具体用量不能简化为“节点数量等于空泡损耗”的固定换算。

## 十六、0年后的系统性崩溃

点燃历史首先破坏人类关于历史连续性的庞大神秘叙述，并让其中残缺部分短暂取得现实兑现权；现代社会的大量功能依赖身份、授权、资质、所有权和组织历史，因此同时遭到现实与制度后果。

0年后立即失去可靠性的系统包括：

- 政府合法性与军事指挥链；
- 身份认证、合同和财产权；
- 企业与专业资质；
- 交通、通信与物流调度；
- 医疗和基础设施维护体系；
- 金融与跨区域行政系统。

即使设备本身没有损坏，只要关键人员和组织关系断裂，系统仍会停止运行。

## 十七、人口崩塌与恢复

点燃历史前，全球人口约为70亿至80亿。现行人口史以约75亿作为工作基准，不将其视为精确统计值。

0日发生大规模历史连续性损失，但无法可靠统计当日仍然存在的人口。档案、身份、记忆与统计体系本身同时受损，因此不设定“0日结束时”的精确数字。

点燃历史后的最初数年，全球人口迅速下降至约20亿至25亿。这个数字同时包括0日的直接损失，以及随后由基础设施、医疗、物流、战争和异常造成的早期连锁死亡，不应被解释为全部人口在同一瞬间消失。

此后人口仍继续下降，主要原因包括：

- 幸存人口高度集中于白塔核心火种、区域节点、次级庇护区和少数自然幸存区域，无法继续维持前文明的平均地理分布；
- 超大型城市、工业区和高度依赖跨区域供应的人口核心失去维护，库存耗尽后出现长期饥荒、疾病与迁徙死亡；
- 农业并未全部消失，但灌溉、化肥、运输、种子、机械和行政组织的断裂使大量高产体系无法维持；
- 灾后婚姻、抚育、医疗和公共卫生条件恶化，儿童死亡率上升，生育率长期低迷；
- 许多节点在0年后数十年内仍会失败，早期幸存不等于能够形成稳定社会。

全球人口在50年至100年间抵达约2亿至3亿的最低谷。该数字代表人类文明连续性接近失败，而不是人类均匀散布在废墟中继续生活；绝大多数人口已经集中在能够维持食物、卫生、教育、工业和组织关系的节点及其辐射区。

随着稳定节点重新扩张、交通恢复、公共卫生改善和地方工业重建，人口才开始持续回升。当前采用的概略时间线为：

| 时间 | 全球人口 |
|---|---:|
| 点燃历史前 | 约70亿至80亿；工作基准约75亿 |
| 0日 | 无法可靠统计 |
| 最初数年 | 约20亿至25亿 |
| 50年至100年 | 约2亿至3亿，人口最低谷 |
| 150年 | 约3亿至4亿 |
| 250年 | 约6亿 |
| 332年 | 约8亿 |

若以100年时约2.5亿至3亿为低谷起点，恢复到332年的8亿所需长期平均年增长率约为0.4%至0.5%。这一速度不要求持续极端人口政策，但依赖数百年内食物、卫生、住房、教育与安全条件整体改善，也允许不同地区经历完全不同的人口轨迹。

因此，332年的8亿人口不代表前文明人口被大量原样保存下来，而是节点保存、非计划幸存与数百年重新增长共同形成的结果。

这八亿人并未重新填满前文明全部居住区，而是高度集中于文明节点、生产腹地和交通走廊。现行区域工作模型见[全球地理与地质异常](../03-地理/全球地理与地质异常.md)。

点燃历史阻止了已知历史啃噬继续向过去扩张，人类作为物种和文明共同体得以存续；代价则是前文明的组织连续性崩溃，人类必须在0年之后重新建立能够支撑下一代的社会。

## 十八、0—332年的重建因果

后文明重建不是全球在某一年同时“恢复”，而是相互重叠的存续、收缩、再组织与扩张过程。一个地区能够进入下一阶段，往往取决于它是否先保住人口、专业人员、最低限度的信用关系和与其他节点的联系；同一时期仍可能有远方节点继续失血或失败。

### 系统存续与节点收缩（0年至约80年）

0年至约20年，幸存者首先维持供水、食物、医疗、能源、仓储、局部通信和能够执行命令的组织核心。政府残部、地方白塔、军队、社区与生产机构在不同地区以不同组合承担治理：有的地方白塔一度兼管避难、生产和异常处置，有的仍由地方政府或军队维持框架，也有社区和企业性组织成为事实上的公共支点。这不意味着所有地方白塔都成为紧急政府、日后再将权力交还；它只是法统中断时为维持社会而出现的多种临时组合。

约10年至80年，能够保住基本系统的节点开始收缩边界、稳定周边，全球整体却仍在失血。人口、机器、燃料、药品与受训人员不能同时保住，许多早期幸存区仍会因补给、疾病、异常或内部冲突而失败。市场和信用并未等到稳定时代才出现：0年至10年，配给、物物交换、仓单和劳务凭证已经与残存货币并存；约5年至40年，地方货币、集市和合作信用在可守住的节点内恢复，用以把生产、修理和日常供给重新接起来。

### 法统分化与区域联系恢复（约50年至140年）

约50年至140年，足以跨越一次领导层更替的稳定节点开始形成可预期的地方制度。紧急期混合在一起的民政、军事、生产和异常管理职能，逐步由常设机关承接并分化；地方白塔回到或形成各自地方法统下的异常管理、专业训练与公共协作角色，而非成为纯白之湖中枢的垂直部门。分化程度并不一致，摩柯等高风险节点仍可长期保留高度交叉的制度安排。

约30年至100年，跨城贸易、地方银行和保险先于完整区域市场恢复。它们的作用是让粮食、燃料、零件与技术不再只能依赖一次性征调，也让维修、迁徙和共同建设能够分担风险。区域联系恢复不是直线扩张：能通行的河道、铁路、港口和空中走廊会反复中断、绕行和重新验证。

### 基建、清算与跨节点工业（约100年至230年）

约100年至220年，区域清算、银行互认、公共债务和基建融资逐步出现，使跨节点的铁路、电力、港口、供水、学校和工业链可以依赖长期承诺而非临时征集。约100年至230年，大型基础设施、金融互认与跨节点工业互为条件：交通扩大市场和维修半径，稳定信用使设备、库存和教育得以跨多年投入，标准与档案互认则降低了协作成本。

### 复利式加速与稳固文明（约200年至332年）

约200年后，跨区资本配置和消费信贷已可在成熟节点间运作，但并未取代配给、地方互助或公共工程。这里所谓“稳固文明”，不是旧世界已经恢复，也不是全球安全，而是多个核心节点能够跨代延续、跨区互保，且不再依赖少数火种人员或五级神秘使持续救援。

200年至332年的加速来自人口回升、交通与标准网络效应、长期信用，以及在新历史中成长的第二、三代教育人口；当更多资源从单纯维生转向科研、民生、维护和专业教育，成果又反过来提高节点的存续率。不同地区进入这一循环的时间差很大，后文明的繁荣因此始终是不均匀的。

### 铁脊：线性文明设施

“铁脊”不是一条从原海参崴直达西欧、由同一列车连续运行的现代铁路，而是跨越西伯利亚的铁路节点链与接驳体系。0年至20年，人们确认尚可使用的旧线并进行局部抢修；约20年至40年，铁路、临时桥、渡船、冰道和公路接驳共同构成不稳定的接力运输。约40年至50年，原海参崴至西欧首次完成有记录的全程接力运输，后称“铁脊贯通”；途中可以多次换轨、换装和等待，时间、季节、运量与安全都没有保证。

约70年至100年，铁脊才形成季节性、低频的定期运转；100年后随着节点补给、维护体系和异常保障逐步稳定，才缓慢接近可靠主干。约150年至200年，主要干线的全年运量、调度能力和维修冗余才接近前文明西伯利亚铁路的水平。建设惨烈并非抽象的牺牲叙事，而是沿线节点长期缺粮缺人、桥梁与冻土反复失效、燃料与机车型号混杂、异常保障不足，以及疾病和异常沿接驳点传播、关键节点多次失败的共同结果。

### 航空与远洋的恢复

0年至20年，少量幸存飞机依靠拆件承担侦察、医疗和其他战略任务；约20年至50年，强节点已经能够制造简单滑翔机、木布结构飞机和活塞机。约50年至100年，灾后供应链生产的第一代标准化飞机用于低频、高风险的区域邮件、医疗与人员运输。约100年至160年，机场、机械与模拟导航、气象和异常观测、维修认证逐步成形，可靠的中远程机开始出现；约150年，后文明工业制造、能够适应异常气象的远程重型机，或首条低频定期跨洋航空线，已经可能出现。约200年至250年，系统性的航空网络才初步形成。飞机始终主要服务人员和轻量紧急货物，大宗运输仍由海运和铁路承担。

海运的恢复同样由个人开路转为制度接力。圣地亚哥在0年前已是资深四级，约30年成为五级；0年至30年主要参与沿岸、岛链恢复和高风险探索。约40年至50年，西欧至原美国东海岸的稳定港口之间首次完成有记录、并带回海图与异常资料的往返。至约100年，各主要大洲之间至少打开一条验证航路，但难度和所需时间并不相同；约100年至150年，港口、修船、海图、观测、护航、通信、检疫和救援逐步构成体系，约150年形成初步成熟的跨洋网络，普通船队不再必须依赖圣地亚哥本人。

## 十九、现实解释权削弱与异常稳定化

点燃历史后，现实轴对地球世界的解释垄断永久性大幅下降，但变化不是所有物理规律按同一比例失效。

可能因素包括：

- 玉石俱焚的伴随否决；
- 文明级历史叙述碎裂后的连带外显；
- 主否决误伤其他解释权边界；
- 历史啃噬残余；
- 群星携带的异质解释秩序继续干涉；
- 多种机制共同作用。

正常物理、生物与化学规律仍然长期有效。变化主要表现为更多神秘叙述能够取得局部解释权：天然异常更容易稳定，神秘使数量上升，短暂外显能够长期维持，群星相关效应也更加明显。

一种边缘假说认为，伴随否决损伤了【地球完整服从太阳常态】之类的深层裁决关系。若该假说成立，0年后的异常时代不仅来自历史破碎，也来自太阳对地球的现实解释权被永久削去一部分。现有观测无法验证这一具体目标。

0年后的异常爆发不能全部归因于群星、历史啃噬、玉石俱焚或太阳裁决损伤中的任一单独来源。

## 二十、点燃历史是否成功

截至332年，已知历史啃噬扩张停止，历史侵蚀指标大幅下降，尚未确认其跨越0年历史断层继续向更早过去扩张。

但人类无法证明：

- 所有历史通路均已断裂；
- 不存在极弱残余路径；
- 不存在隐藏污染；
- 不存在尚未发现的历史“孢子”。

因此白色高塔只能确认：

> 截至目前，没有已知证据证明历史啃噬已经跨越0年断层继续扩张。

这不等于目标被消灭。

人类同样无法区分0年灾难中哪些结果来自主否决指称误差、残缺历史叙述的现实兑现、现实重新闭合、伴随否决、历史啃噬残余、太阳裁决损伤或后续异常。玉石俱焚所造成的全部“相称代价”至今未被确认。

## 二十一、白塔与摩柯的后文明连续性

白色高塔得以延续，并不是因为它在0年前已经成为统辖各国内政的统一世界政府，而是因为纯白之湖空泡保存了共同机构核心、关键人员、母床、数据库、神秘使体系和异常处置能力。

大量旧机构失效后，白塔共同体成为少数仍能跨地区提供标准、技术、救援与风险管理的连续体系。纯白之湖中枢保存了共同档案、关键设施与火种，但各地白塔仍在各自地方法统下重建和运作；中枢并未取代地方政府或成为其垂直上级。

[摩柯](../03-地理/摩柯.md)则从前伦敦区域的白塔节点发展为现代人类最重要的神秘学城市之一。它不是世界首都，白塔中枢也不是摩柯政府；纯白之湖作为中枢驻地带来的优势，不构成摩柯对中枢或其他地区的主权。三者高度合作，但保留各自行政与组织边界。

332年的纯白之湖中枢不再是孤独火种；白塔共同体已经成为多个文明核心之间的知识、技术、标准与异常协作网络。

## 二十二、未决问题

以下内容仍未最终确定：

- 群星影响太阳系的完整时间尺度；
- 地球在人类以前是否曾被其他智慧观察；
- 太阳系常态的解释权来源；
- 日心裁决假说是否包含任何真实机制；
- 历史啃噬的来源、边界与残余状态；
- 点燃历史发生的前文明公历年份；
- 0年直接人口损失；
- 全球计划节点与成功节点数量；
- 纯白之湖的形成机制及其与禁绝材料的确切关系；
- 白塔建筑高度、内部结构与建设时间；
- 玉石俱焚伴随否决的规律与真正代价；
- 点燃历史是否损伤太阳常态对地球的裁决关系；
- 生玉异常与玉石俱焚究竟是两个主体还是一个复合结构的两种表现；
- 前文明不同地区与年代资料的具体可靠程度。
