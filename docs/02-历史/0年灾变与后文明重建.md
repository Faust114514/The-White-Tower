# 0年灾变与后文明重建

## 十五、文明火种体系

前文明对关键火种人员实施了特殊历史处理，尽量保护【此人现在存在】，同时减少其当前存在对复杂过去关系的依赖。

这类人员可能在0年后保持身体、人格、知识与主要记忆，却失去大量旧历史关系的神秘学可追溯性，并从0年开始重新积累稳定历史。

火种保存并不只依赖白塔。整个体系包括：

1. **白塔核心火种：** 保存最难重新获得的高阶神秘使、工程师、科学家、医学与农业专家、母床、数据库、样本和关键设备；
2. **区域节点：** 维持具有水、食物、医疗、教育、能源、工业、神秘使与基本行政能力的完整社会；
3. **次级庇护区：** 地下设施、军事基地、地方避难所、稳定设施与物资中心；
4. **非计划幸存者：** 依靠地理、自给能力、船队、地方神秘使或偶然保护存续的个人和社区。

节点建设会使用禁绝材料，其中部分高等级设施需要原生样品作为稳定核心。纯白之湖矿床的工业价值因此与空泡保存发生直接张力。

白塔优先以嬗变材料和可量产合金满足常规需求；涉及纯白之湖原生样品的开采，必须同时评估节点收益与空泡长期损耗。具体用量不能简化为“节点数量等于空泡损耗”的固定换算。

## 十六、0年后的系统性崩溃

点燃历史首先破坏历史连续关系，而现代社会的大量功能依赖身份、授权、资质、所有权和组织历史。

0年后立即失去可靠性的系统包括：

- 政府合法性与军事指挥链；
- 身份认证、合同和财产权；
- 企业与专业资质；
- 交通、通信与物流调度；
- 医疗和基础设施维护体系；
- 金融与跨区域行政系统。

即使设备本身没有损坏，只要关键人员和组织关系断裂，系统仍会停止运行。

## 十七、人口崩塌与恢复

0日发生大规模历史连续性损失，但点燃历史没有在单日内把全球人口直接降至最低点。

随后数周，供水、电力、交通、医疗、通信和行政系统大规模失效。最初数年，饥荒、疾病、战争、异常、迁徙、历史余燃和神秘使失控共同造成最严重的人口下降。数十年后，全球人口才逐渐接近最低点。

因此“人类由数十亿下降至数百万”是对一段长期崩塌过程的历史概括，不是0日精确统计。

点燃历史后的最初百余年仍以生存、重新联络节点和阻止进一步灭绝为主。完整再工业化、跨节点基础设施与成熟神秘学工业经历了更长恢复。

故事时代为332年，全球人口约8亿。该数字用于确定当前世界规模，仍可随人口史细化调整。

## 十八、常态削弱与异常稳定化

点燃历史后，地球常态对异常外显的压制永久性大幅下降，但原因无法单独确认。

可能因素包括：

- 玉石俱焚的伴随否决；
- 文明级历史关系损伤的连带效应；
- 对邻近深层结构的误伤；
- 历史啃噬残余；
- 多种机制共同作用。

正常物理、生物与化学规律仍然长期有效。变化主要表现为天然异常更容易稳定，神秘使数量上升，短暂异常能够长期外显，群星影响也更加明显。

0年后的异常爆发不能全部归因于群星、历史啃噬或玉石俱焚中的任一单独来源。

## 十九、点燃历史是否成功

截至332年，已知历史啃噬扩张停止，历史侵蚀指标大幅下降，尚未确认其跨越0年历史断层继续向更早过去扩张。

但人类无法证明：

- 所有历史通路均已断裂；
- 不存在极弱残余路径；
- 不存在隐藏污染；
- 不存在尚未发现的历史“孢子”。

因此白色高塔只能确认：

> 截至目前，没有已知证据证明历史啃噬已经跨越0年断层继续扩张。

这不等于目标被消灭。

人类同样无法区分0年灾难中哪些结果来自主否决误伤、伴随否决、历史啃噬残余、常态削弱或后续异常。玉石俱焚所造成的全部“相称代价”至今未被确认。

## 二十、白塔与摩柯的后文明连续性

白色高塔得以延续，并不是因为它在0年前已经成为世界政府，而是因为纯白之湖空泡保存了组织核心、关键人员、母床、数据库、神秘使体系和异常处置能力。

大量旧机构失效后，白塔成为少数仍能跨地区提供标准、技术、救援与风险管理的连续组织。

[摩柯](../03-地理/摩柯.md)则从前伦敦区域的白塔节点发展为现代人类最重要的神秘学城市之一。它不是世界首都，白塔也不是摩柯政府；二者高度合作，但保留各自行政与组织边界。

332年的白塔不再是孤独火种，而是多个文明核心之间的知识、技术、标准与异常协作节点。

## 二十一、未决问题

以下内容仍未最终确定：

- 群星影响太阳系的完整时间尺度；
- 历史啃噬的来源、边界与残余状态；
- 点燃历史发生的前文明公历年份；
- 0年直接人口损失；
- 全球计划节点与成功节点数量；
- 纯白之湖的形成机制及其与禁绝材料的确切关系；
- 白塔建筑高度、内部结构与建设时间；
- 玉石俱焚伴随否决的规律与真正代价；
- 生玉异常与玉石俱焚究竟是两个主体还是一个复合结构的两种表现；
- 前文明不同地区与年代资料的具体可靠程度。
