# 《白色高塔》世界观基础框架

> 状态：现行设定  
> 最后更新：2026-08-23  
> 本文规定【现实】、【神秘】、智慧观察、解释权与异常的最低共同框架。旧版“信息／意义一元论”“现实偏移／现实密度”及把意义厚度直接等同于异常强度的解释不再采用。

## 一、设定的权威层级

本仓库使用四种表述层级：

- **作者确定事实**：世界中确实如此，除非后续明确修订。
- **白塔工程模型**：能够稳定解释、预测和利用现象，但不保证等于宇宙本体。
- **白塔学术假说**：有一定证据支持，仍存在竞争性解释。
- **未知／开放问题**：当前不回答，也不应由后续文档擅自补完。

正文若未特别标注，基础现象按作者确定事实处理；关于太阳、群星、域外观察者以及世界为何允许解释权竞争的回答，默认不高于白塔工程模型。

## 二、世界与两种描述

【现实】与【神秘】不是两个空间、两种物质或彼此平行的宇宙。

它们是对同一个世界的两种描述方式：

- **【现实】**通过物质、能量、物理规律、生物过程和连续因果描述世界；
- **【神秘】**通过身份、意义、象征、指称、关系、叙事与历史解释世界。

在足够高的尺度上，两者都不是世界本体，只是世界能够以何种方式被理解和规定。人类把二者截然分开，首先源于自身所处环境和认知尺度，而不是已经证明宇宙天然分成两层。

## 三、太阳系常态与现实主导

至少在已知太阳系内，【现实】长期占据压倒性的解释主导地位。

在近似绝对常态下，世界首先按照物理与生物过程发展，【神秘】只能随已经发生的现实同步更新：

> 现实发生  
> → 智慧生命观察、记忆并解释  
> → 神秘叙述形成

这不表示【现实】比【神秘】更接近宇宙真理，只表示当两种描述发生冲突时，太阳系环境通常只兑现现实描述。

白色高塔把这种对现实解释的稳定偏向统称为“常态”。常态不是一个简单能量场，也不能被证明是全宇宙默认状态。

太阳及整个太阳系长期关系可能是本地常态的主要支撑，但“稳定、古老、庞大”只能解释一套描述为何牢固，不能单独解释它为何拥有裁决其他描述的权限。完整讨论见[异常天文学](../04-神秘学/异常天文学.md)。

## 四、智慧观察与意义的产生

【神秘】必须有能够形成解释的智慧观察者才会产生实际内容。

没有任何智慧观察者时，宇宙仍可按照物理规律运行，但天空不会具有【辽远】【开阔】【崇高】，血液不会具有【亲缘】【牺牲】【危险】，一座山也不会具有【守望】【边界】【不可动摇】。这些意义不是物质自带的宇宙词条。

“观察”不等于光线进入感官或设备留下数据。能够产生神秘学意义的观察至少涉及：

- 把目标识别为相对连续的同一对象；
- 对目标形成内部表征；
- 将目标纳入概念、关系或叙事；
- 能够区分“它是如此”与“它也可能并非如此”；
- 建立足够明确的指称。

无意识仪器不能自行创造意义，但可以替设计、使用或继承它的智慧主体承载观察关系。

## 五、意义受到现实约束

意义由智慧观察产生，不等于意义可以被任意指定。

现实为观察者提供反复出现的结构、差异与后果，观察者依据自身感官、身体、生活和社会经验对其进行归纳。

血液之所以容易与【生命】【伤害】【亲缘】【牺牲】联系，不是因为宇宙预装了这些属性，也不是因为某个人可以随口决定，而是因为失血、出生、遗传、暴力和死亡在现实经验中反复相关。

因此至少要区分：

1. 现实中的对象、事件与关系；
2. 智慧生命能够感知和区分的经验；
3. 观察者据此形成的概念与叙述；
4. 表达这些概念的文字、语言、图像和仪式。

表征不是意义本身，但能够承载、强化和重新指向意义。

## 六、人类不是唯一可能的解释者

人类创造了全部已知的人类神秘学语汇，但没有证据证明【神秘】只能由人类解释。

其他智慧生命若曾经观察、理解或指称地球，也可能留下非人类的神秘叙述。观察者不必生活在地球，不必与人类同时存在，也不必使用人类能够理解的感官和概念。

因此必须区分：

- **人类意义**：由人类经验、语言、历史与社会形成；
- **非人类意义**：可能由其他智慧观察者形成，人类通常只能从外显后果反向归纳；
- **前意义结构**：客观存在、能够被观察和解释，但在观察发生前尚不具有具体神秘语义的现实结构。

白塔无法确认地球在人类以前是否曾被其他智慧观察者认识。部分天然异常可能是古老现实结构在人类观察后获得意义，也可能是更早观察留下的神秘学痕迹；现有证据不能统一判定。

## 七、异常的本质：解释权竞争

意义厚重不等于异常。

一段被全人类长期共享的叙述，如果不能影响世界如何兑现，仍然只是文化、记忆或社会事实。一个意义非常稀薄的结构，如果能够短暂夺取足够多的解释权，也可能造成巨大现实后果。

异常的最低定义是：

> **某段【神秘】叙述取得了原本由【现实】垄断的局部解释权，并使世界按照该叙述成立。**

异常不必反对现实、制造混乱或改变物体外观。只要某种性质绕过正常物理机制，由神秘叙述直接获得持续或瞬时兑现，它就是异常。

因此【保持自身】【拒绝外来神秘规定】【只服从正常物理过程】同样可以成为异常叙述。禁绝金属会用神秘解释权维持近似现实的结果；假如太阳常态本身由某段神秘叙述维持，它也不会因为作用方向偏向现实就失去异常性质。

普通自然过程主要表现为：

> 现实状态产生可以被智慧生命解释的意义。

异常则允许反方向成立：

> 已经形成的神秘叙述取得现实兑现权。

白色高塔把这个过程称为“外显”。外显不是意义变多，也不是抽象能量释放，而是解释权的实际转移。

## 八、解释权不是单一百分比

“现实占据百分之百解释权”是描述绝对常态的思想实验，不是可直接测量的宇宙数值。

实际解释权具有明确的对象、关系和作用方向。

一把异常刀可能只在【能否切开当前目标】上由神秘叙述取得优势，而其质量、温度、惯性和运动仍由现实解释。某个身份异常可以规定一个人的社会位置，却不能因此改变重力或化学反应。

因此白塔评估异常时必须同时询问：

- 哪一段神秘叙述正在争夺解释权；
- 它指向哪个对象和哪种关系；
- 它能够夺取多大范围、持续多久；
- 它与目标及环境中的其他叙述如何冲突；
- 现实主导恢复后，已经形成的后果是否继续存在。

解释权是分对象、分关系、分领域的，不存在能够解释所有现象的统一“现实百分比”。

## 九、意义厚度与解释权必须分离

意义厚度主要来自：

- 观察者数量与持续时间；
- 共同经验和反复确认；
- 物证、记忆、记录与制度；
- 与其他意义的关系数量；
- 叙述内部的自洽和冗余；
- 对象已经形成的现实历史。

厚重意义通常更稳定、更难被否决，也能在遭到破坏后留下更多相互矛盾的残片。但厚度本身不会自动产生异常，也不保证能够夺取现实解释权。

异常结构是否能够取得解释权、能够取得多少、沿什么方向取得，是另一项独立性质。

这个区别解释了：

- 史诗、宗教与国家可以意义极厚却从不异常外显；
- 瞬态异常可以意义稀薄却在数秒内造成灾难；
- 六级异常可怕之处首先在于能够在强常态下持续取得解释权，而不只是概念古老；
- 历史遭到否决时往往不会干净消失，而会因叙述过于厚重产生碎裂、冲突与重新兑现。

## 十、指称、关系与解释范围

神秘叙述必须真正指向目标，才可能争夺该目标的现实解释权。

名字具有神秘学价值，不是因为字符串天然有力量，而是长期使用、本人承认、他人称呼和历史记录共同建立了稳定指称。

常见指称媒介包括：

- 长期使用的姓名；
- 血液与身体组织；
- 亲笔文字；
- 长期持有物；
- 面对面的直接观察；
- 深厚且明确的历史关系；
- 能够保持目标连续性的档案与设备。

“真名”更适合被理解为低歧义、深关系的指称工程，而不是宇宙分配的唯一编号。

非人类意义未必服从人类的概念边界。人类对天然异常使用的名称与标签，可能只是把异质叙述翻译成可以操作的近似接口。

## 十一、人类与神秘解释权

如果人类是某一范围内唯一能够产生意义的智慧观察者，那么人类便垄断该范围内神秘语汇的原生生产，但不因此自动控制神秘的现实兑现。

人类也不是一个统一意识。不同文化、时代、群体和个人可能对同一对象形成彼此矛盾的解释。这些叙述可以并存、竞争、分化或互相覆盖。

因此更准确的说法是：

> 人类拥有对自身经验与社会最深的第一人称解释关系，但没有获得对宇宙全部神秘意义的总控制权。

普通思想、想象和社会观念仍需通过身体、语言、制度等现实机制产生普通因果。只有在解释权发生转移时，语义内容本身才会成为直接现实原因。

## 十二、神秘使与基本释术

神秘使是能够主动组织神秘叙述，并使其争夺局部现实解释权的人格主体。

现代释术通常被概括为：

> 指称 → 构义 → 闭合 → 外显 → 现实竞争

- **指称**：确定这段叙述究竟在谈论谁或什么。
- **构义**：使用自身能够理解的意义建立希望成立的叙述。
- **闭合**：排除杂念、歧义和无关关系，使叙述保持可执行的一致性。
- **外显**：令叙述取得一定现实兑现权。
- **现实竞争**：与目标当前状态、物理因果、历史、环境、常态和其他神秘叙述发生作用。

神秘使没有凭空制造宇宙词条。他们只能使用自身能够形成、理解和稳定承载的意义，并受人类感官、文化与认知边界约束。

## 十三、奇物、母床与神秘学工业

奇物制造不是向物品灌入抽象点数，而是让一段可重复的神秘叙述与物品建立稳定关系，并为它提供受控的外显条件。

例如制造具有【造成死亡】倾向的弹药，关键不只是让它接触死亡，而是通过材料、仪式、使用记录、受控事件和指称结构，使“它能够导致目标死亡”成为可稳定调用的叙述。

母床则把指称、构义、边界和外显条件工程化，使同类叙述能够在不依赖单次完整人工释术的情况下重复取得有限解释权。

典型发展路径仍是：

> 天然异常 → 简单奇物 → 约束设备 → 加工设备 → 奇物生产母床 → 神秘学工业体系

部分高级工业依赖人类无法理解其原始语义、却能稳定利用其外显接口的天然异常。

## 十四、语义提纯

任何观察与事件都会形成大量相互纠缠的意义。

一次死亡可能同时涉及疼痛、恐惧、血、谋杀、处刑、失去、终结和具体人物关系。语义提纯不是发现宇宙中预装的概念粒子，而是从人类能够形成的复杂叙述中，尽量隔离当前工艺需要的部分。

所谓“高纯度死亡模因”，只表示在现有人类观察、检测与工艺边界内，样品对目标叙述的指向足够集中、稳定和可重复。

## 十五、认识论边界

白色高塔能够：

- 测量不同条件下解释权转移的外显结果；
- 归纳人类意义与异常之间的关系；
- 设计术式、奇物和母床；
- 建立工程标准；
- 对部分现象进行可靠预测。

这些成就不能证明：

- 人类概念等同于宇宙普遍概念；
- 人类是唯一智慧观察者；
- 天然异常的原始叙述来自人类；
- 太阳系常态等同于宇宙默认状态；
- 现实与神秘是世界本体的最终分层；
- 白塔已经知道解释权为什么能够转移。

神秘学研究的是“哪些叙述能够在什么条件下成为现实”，不是宇宙终极代码。

## 核心原则

> 【现实】与【神秘】是对同一个世界的两种描述，不是两个平行宇宙。

> 【神秘】必须由足够强的智慧观察产生；没有观察者，就没有具体神秘学意义。

> 意义由观察者形成，但受到现实结构、感官经验和指称关系约束。

> 人类创造人类神秘学语汇，却未被证明是宇宙唯一的解释者。

> 意义厚度决定叙述有多稳定；异常性决定叙述能否取得现实解释权。

> 异常，是【现实】的解释垄断出现局部破口。

> 异常不等于反现实；神秘叙述也可以利用解释权维护现实、稳定与禁绝。

> 神秘使，是尝试主动书写并兑现神秘叙述的人。
