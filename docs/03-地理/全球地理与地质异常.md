## 一、后文明地缘政治基本结构

点燃历史后，旧国家体系基本瓦解。现代世界的主要政治单位逐渐变为以幸存节点为核心的**城邦、城群与区域联盟**。

后文明整体具有以下特征：

- 地理隔绝程度远高于前文明；
- 大部分节点拥有较高自治权；
- 大型国家没有简单以原国界恢复；
- 前文明工业、人口、科研和白色高塔合作基础仍显著影响幸存概率；
- 少数地区因异常、地理或高阶神秘使作用，出现与前文明实力完全不相称的崛起；
- 白色高塔并非世界政府，但绝大多数文明都不同程度嵌入其标准、神秘学工业和异常管理体系；
- 前文明越深度参与白塔体系的地区，后文明通常越难完全脱离白塔；
- 部分边缘地区反而更容易发展出独立体系，薄雾群屿是典型案例。

旧城市名称往往因历史指称风险被废弃。部分旧国名、城市名乃至少数高历史耦合文字也被白塔主动处理。

## 三、现存五级神秘使

人类历史上确认出现过约五位稳定五级神秘使，目前仍有四位存世。

- **爱莎**：位于摩柯，与白色高塔体系联系最深。
- **[伊妮娅·维登斯](../05-人物/伊妮娅.md)**：前文明时期已经达到五级；0年后的系统崩溃期承担跨区域紧急干预，并协助各地重建本地处置能力；约百年后随文明体系恢复而退出常态化行动，定居薄雾群屿并成为群屿初代女王。
- **寒霜的五级神秘使**：寒霜北方防线的核心之一，与整座城市的【拒绝】【守住】【不受管辖】结构长期共同作用。
- **海上的老人**：约在点燃历史后百余年成为五级，长期与海洋文明及远洋航路体系相联系。

五级代表的是异常作用在特定意义关系上的极高强度，而非单纯破坏力。

## 四、地理与地质级异常

地理、地质结构的现实基础不由人类创造。山脉、海洋、板块、极点和赤道所对应的物理结构，可以在没有智慧生命时长期存在。

但这些结构的【边界】【承载】【深远】【孤立】【中心】等神秘学意义必须由足够强的智慧观察产生。人类形成了大量地理意义，却没有证据证明人类是唯一曾经解释地球的观察者。

因此必须分开：

1. **现实结构年龄**：地质或天文结构实际存在了多久；
2. **观察叙述年龄**：人类或未知观察者何时开始认识并解释它；
3. **异常外显年龄**：相关叙述何时开始取得现实解释权；
4. **人类发现时间**：白塔何时获得可重复记录。

地理结构存在数十亿年，不能单独证明其神秘叙述同样古老，也不能直接换算为异常等级。

部分结构的研究状态如下：

| 结构 | 人类常用解释 | 当前工程状态 |
|---|---|---|
| 地壳与地表 | 【承载】【覆盖】【地表／地下分隔】 | 现实结构极深；未确认存在统一人格或单一全球异常 |
| 南北极 | 【方向极限】【轴端】【最北／最南】 | 存在局部异常与稳定统计偏差；不能把全部极区视为同一异常 |
| 赤道 | 【南北分界】【跨越】【两半】 | 人类定义与地球物理关系高度稳定；未确认其本身外显，不赋予异常等级 |
| 全球海洋 | 【广阔】【连通】【深处】 | 现实与人类叙述均极复杂；无证据支持统一异常主体 |
| 大型板块与边界 | 【移动】【挤压】【分离】 | 部分区域存在地质异常；必须逐区建档 |
| 大型海沟 | 【深】【进入地下】【俯冲】 | 可能同时承载人类与未知观察叙述；来源未定 |
| 尼莫点 | 【远离陆地】【孤立】【远离人类】 | 人类地理定义明确；是否外显需独立证据 |

人类关于土地、地底和海洋的文化会形成真实神秘叙述，但不应反推出地球在无人观察时便拥有同样概念。

某些地质异常表现得过于古老或不符合人类概念，可能来自非人类观察遗留，也可能是古老解释权通道在后来承载了人类意义。两者目前无法统一区分。

## 五、异常强度与危害等级必须分离

异常强度与对人类的危害程度是两个独立维度。

**异常强度**主要描述：

> 该结构在现实主导与其他神秘叙述竞争下，能够多稳定地取得并保持自身方向的解释权。

**危害等级**描述：

> 如果不加控制，它对人格主体、社会和文明可能造成多严重的实际损失。

因此：

- 西安可以形成总体保护人类的高强度异常；
- 无限传播的恐惧可能只能短暂外显，却具备文明毁灭级危害；
- 京津冀既能长期维持身份与治理解释，又具有极强扩张性，因此同时属于高强度、高危异常；
- 地壳、赤道和海洋即使极其古老重要，只要未确认神秘外显，就不能仅凭意义厚度获得异常等级。

强度不能以核爆当量、概念重要性或结构年龄替代。

## 六、异常化不是意义积累的必然结果

必须避免“凡是历史悠久或被很多人相信的东西最终都会异常化”。

需要区分：

1. 智慧观察形成了什么神秘叙述；
2. 叙述具有多少历史、记忆和关系冗余；
3. 叙述是否取得现实解释权；
4. 它取得解释权后能作用到什么对象和领域。

国际千克原器、本初子午线、重要城市、语言、文字和制度都可以拥有巨大人类意义，却从未因此自动异常化。

人类文明历史相对地质结构很短，不能据此判断人类意义“不够资格”形成高等级异常。决定异常性的关键不是累积年数，而是解释权通道；历史厚度主要影响叙述的稳定、抵抗和后果复杂度。

0年前后人类相关异常大量增加，主要因为：

> **点燃历史与群星干涉共同削弱了现实对人类历史、身份和社会关系的解释垄断。**

北京、西安、湘雅等异常并不是意义终于积累到阈值，而是已有的人类叙述在新的解释权环境中获得了直接兑现能力。

## 七、天然异常与人工异常

“天然异常”表示其外显不是现有人类工程主动设计，不表示其意义能够脱离智慧观察自然生成。

天然异常可能包含：

- 古老现实结构；
- 人类长期观察形成的叙述；
- 未知非人类观察留下的叙述；
- 本来已经存在的解释权破口；
- 后来命名、实验和处置形成的人类叙述覆盖层。

白色高塔无法仅凭“发现于自然环境”判断其原始作者和语义。

人工异常工程则主动设计：

- 希望形成的神秘叙述；
- 目标和指称；
- 叙述载体；
- 外显条件与解释权通道；
- 失败边界和常态恢复方案。

寒霜城是典型的大型人工解释权工程。

最初的【拒绝京津冀治理】来自真实历史和人类共同理解，随后由五级神秘使、白塔工程师、大量奇物、城市制度与数百年成功防御持续闭合并外显，最终令整座城市在【是否接受外来治理】上形成稳定保护结构。

白塔进行此类工程极为谨慎，尤其不会轻易把全球计量标准、地质结构、极端重要历史对象、全球性语言概念和大型城市接入未经验证的解释权通道。

核心风险不是“意义太多会自动醒来”，而是：

> **一旦某个巨大而复杂的人类叙述获得现实兑现权，就可能产生无法完整指称、隔离和撤回的后果。**

因此白塔异常工程的一条基本原则可以概括为：

> **不要把尚且只存在于解释中的庞然大物，轻易交给世界执行。**
