# 《白色高塔》术语表

> 状态：现行设定  
> 最后更新：2026-08-23  
> 用途：提供跨文档查询接口；本表只固定已经确认的边界，不替代各专题正文，也不补写未定程序或数值阈值。

## 一、描述、意义与解释权

### 现实轴／神秘轴

**现实轴**以物质、能量、物理规律、生物过程和连续因果描述同一个世界；**神秘轴**以身份、意义、象征、指称、关系、叙事与历史描述同一个世界。二者不是两个空间、两种物质或平行宇宙。

不可等同：现实轴不是“已经发生的一切”的同义词；神秘轴不是另一层世界。**现实状态**指某一时刻已经实际成立的事实；**常态／现实主导**指现实轴在竞争中通常被优先兑现的环境关系。

### 神秘学意义、叙述、指称、解释权与外显

**神秘学意义**是物品、对象或关系在神秘轴中承载的可理解内容，例如血液可以承载【牺牲】【奉献】【危险】等意义。它可以被观察、记录、操作、组织和工程化，是奇物形成及大量神秘学工程的基础。

**叙述**是围绕对象、关系和“其应如何成立”组织起来的意义；**指称**是叙述实际指向目标的关系；**解释权**是某段叙述在特定对象、关系和范围内被世界兑现的能力；**外显**是解释权实际转移并产生超常结果的过程或结果。

不可等同：意义厚度不等于异常性；只有神秘轴叙述取得解释权，才会外显。**真名工程／真名联系**是低歧义、深关系的强指称工程，不是宇宙分配的唯一编号，也不是所有异常共用的接口。

### 意义外显过程与闭合

神秘学工程通常按照以下关系理解意义的形成与外显：

> 智慧观察 → 神秘学意义 → 神秘叙述 → 指称、构义与闭合 → 外显 → 解释权竞争

这是一条工程归纳，不是宇宙本体的直接读数。

“**闭合**”必须按语境区分三义：

1. **术式闭合**：排除歧义和无关关系，使叙述可执行；
2. **现实闭合**：异常结果出现后，现实状态在不相容条件上重新建立连续因果；
3. **社会闭合**：身份、制度和关系网络重新形成可持续结构。

三者不可互推。

## 二、异常、人格与技术

### 异常、异常对象、异常主体与异常复合区域

**异常性／异常性质**指神秘轴叙述直接兑现、因而超出正常物理机制的性质。**异常对象／异常现象**是档案记录的对象；**异常主体**是暂可作为单一作用单元处理的异常，不暗示意识或人格；**异常复合区域／结构**由多个载体、叙述或未知机制共同构成，不能预设存在单一主体。

**人格主体**是具有权利、意志和责任能力的个体。人格主体可以具有异常性，但异常分类、档案建立或风险评级均不导致人格降格。

### 处置与收容

**处置**是降低风险、保护人格主体或维持系统的总称，包括监测、协商、救援、隔离、社会支持与工程维护。**收容**是以隔离、限制接触或限制作用范围为核心的一类处置措施，不是异常档案的默认结果；对人格主体实施收容仍须具有独立、相称的法律与事实依据。

### 神秘使、释术、术式、奇物与母床

**神秘使**是能主动组织神秘轴叙述、使其争夺局部现实解释权的人格主体。**释术**是一次实际进行的指称、构义、术式闭合、外显与现实竞争活动；**术式**是可教学、校验和复用的释术结构。

**奇物**是与可重复神秘轴叙述建立稳定关系、具备受控外显条件的物；**母床**是把同类叙述的生产和调用条件工程化的设施或工艺体系。

不可等同：神秘使不是人形奇物；术式不是宇宙代码；奇物与母床也不是单次释术的同义词。

### 色调、传统、专业、职位、等级与执照

**色调／宝石传统**是人类神秘学中形成的认知与释术传统；**专业**是实际处理的问题领域；**职位**是组织内承担的工作角色；**等级**是工程能力评级；**执照／专业资格**是特定活动的制度许可。

不可等同：传统不等于专业，专业不等于职位，等级不等于执照；它们均不自动决定人格价值或政治地位。

### 禁绝材料

**禁绝材料**是以神秘轴叙述维持稳定、抵抗外来神秘规定的异常材料总称。**禁绝金属**是其中以金属为主要载体的工程材料类别，不是单一元素或宇宙天然类别。

- **原生禁绝金属**：非现有人类工程制造的来源描述，不是强度等级；
- **嬗变禁绝金属**：普通材料经人工长期诱导形成的产物；
- **禁绝合金与人工稳定材料**：面向量产和工程性能的工业产物。

化学成分相同，不等于异常个体、历史关系或工程性能相同。

## 三、白塔共同体与制度边界

### 白色高塔建筑、白塔中枢、地方白塔、白塔共同体与白塔体系

**白色高塔建筑**是纯白之湖内的塔状设施。**白塔中枢**（亦称**纯白之湖中枢**）是各地白塔共同设立、驻于纯白之湖的文明级共同机关。**地方白塔**是各地法统下的公共机关。**白塔共同体**由地方白塔、白塔中枢及其共同纲领、标准与互认关系构成；**白塔体系**是共同体进一步形成的人才、设施、工业与协作网络。

“白色高塔／白塔”裸称仅作总称；涉及权力、行动、任职或责任时，应尽量落到上述具体对象。**摩柯**是中枢驻地城市；摩柯政府、摩柯地方白塔与白塔中枢相互合作但彼此不等同，驻地红利不构成摩柯主权。

### 法统、机关资格、个人等级与专业资格

**法统**是地方政治制度赋予机关设立、授权、责任与更替依据的连续关系。地方白塔依其所在地法统运作，不是中枢的垂直分部。

**机关资格认证**是中枢确认某地方机关具备白塔共同协作接口的制度资格；它不改变该机关的法统、内部制度或日常领导。**神秘使等级认证**是对神秘使构造并稳定外显神秘叙述能力的工程评级；异常另行使用异常强度评级。**专业资格／执照**是个人从事特定专业或高风险活动的许可。三者不可互换。

### 文明级

“**文明级**”是作用范围、共同事务或风险覆盖人类文明连续性与跨地区共同结构的尺度词。它不是统一的强度、行政位阶或风险等级；应随语境区分文明级事项、文明级外显、文明级灾害与文明级授权。

## 四、历史、保存与区域

### 历史状态、历史叙述、历史啃噬与点燃历史

**历史状态**是过去实际发生的现实；**历史叙述**是智慧观察者对过去的因果、连续、来源、身份和演化关系形成的解释。**历史啃噬**是能够沿历史叙述争夺过去解释权的六级异常现象。**点燃历史**是为阻断其已知传播通路而实施的特定文明级行动；“点燃历史后”是纪年和时代用法。

不可等同：历史状态不等于历史叙述；现有资料不能确认历史啃噬的完整本体、玉石俱焚的原始语义或点燃历史的全部代价。

### 文明火种、节点与空泡

**文明火种体系**是保存文明连续性的分层体系。**火种人员**是经特殊保存或保护的关键人格主体；**火种资产**包括知识、母床、样本、数据库与关键设备；二者不得混为一谈。

**文明节点**是能够维持食物、卫生、教育、工业和组织关系等完整社会再生产能力的地理—社会单元，正文中常简称为“节点”。**火种节点**是点燃历史前后承担文明保存任务的节点；它可能发展为后来的文明节点，但二者不自动等同。铁路节点、交通节点和白塔协作节点等其他用法必须带修饰语，也不等于单一设施或单一火种。

**空泡**是对白塔观测到的、局部现实连续性异常稳定的区域性现象的工程称呼。**纯白之湖**是已知最重要的天然稳定型异常复合区域之一；它不是异空间，也不等于其矿床、中枢、白色高塔建筑或摩柯。

## 五、工程评级

### 异常强度、外显效力与危害度

**异常强度**描述异常取得、保持和恢复解释权的能力；**外显效力**描述其取得解释权后能沿自身方向让多少世界事实服从；**危害度**描述其在具体环境中对人格主体、社会和文明造成实际损失的可能性与严重程度。三者均为工程评级，不能互相换算。

异常强度的一至六级与神秘使一至六级是不同体系，均不是宇宙位阶或人格价值判断。

### 危害度字母级与K级

危害度统一使用 **E、D、C、B、A、K** 六级；E 为当前已知风险最低的一端，K 指文明存续层面的风险或后果。E—A可使用一个或两个同向的 `+` 或 `-` 作细分，不得混用正负号；K级内部分类不在本表展开。现阶段不规定各级的数值阈值。

不可等同：K级不是异常强度、神秘使等级、外显效力或中枢授权的同义词。
