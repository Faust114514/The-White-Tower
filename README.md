# 《白色高塔》设定库

《白色高塔》新版世界观、历史、地理、神秘学与人物设定的统一资料库。

## 当前基线

- 故事开始时间为点燃历史后332年。
- 全球人类人口已恢复至约8亿。
- 现实轴与神秘轴是对同一世界的两套描述；异常的根本性质，是神秘轴叙述取得了直接规定世界的解释权。
- 任何确实违背正常物理规律的性质都属于异常，包括以【禁绝】或现实稳定化为结果的性质。
- `docs/` 保存现行设定，`archive/` 仅保存历史版本和原始数据。
- 发生冲突时，以 `docs/` 中更新时间较新的明确表述为准；仍无法判断时，将问题标记为待定，不自行补完。

## 维护原则

1. 新设定优先写入对应主题文件，不以聊天记录代替正式文档。
2. 被推翻的内容移入 `archive/`，不要直接删除。
3. 一次提交尽量只处理一个主题，以便查看差异和回退。
4. 尚未决定的内容明确写作“待定”或建立 Issue，不把推测写成定论。
