# 薄雾群屿

> 状态：现行设定  
> 最后更新：2026-08-20

薄雾群屿位于前印度尼西亚群岛及其周边海域，是后文明最重要的海洋文明核心之一。

整个区域长期笼罩于一种约五级的巨型有益异常【薄雾】之中。薄雾显著缓和当地原本炎热湿润的赤道气候，并削弱赤道异常在区域内的外显效应，使群岛成为少数能够较稳定跨越南北半球的海域。

依托天然良港、密集岛链以及数百年的航海传统，薄雾群屿形成了世界顶级的造船、修船、远洋航运与海洋神秘学工业，是东亚、印度洋、大洋洲与南半球诸节点之间最重要的交通枢纽之一。

群屿政治独立性极高。[伊妮娅·维登斯](../05-人物/伊妮娅.md)是薄雾群屿初代女王，曾实际承担约三十年的主要统治责任。现代群屿拥有独立政府、法律和行政体系；伊妮娅保留女王身份及重大危机中的最终介入能力，但通常不参与日常行政。
